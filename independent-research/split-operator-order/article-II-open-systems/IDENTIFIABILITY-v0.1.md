# Holonomy identifiability: no-go and finite qubit reconstruction

**Article II research note — v0.1**  
**Author:** Malachevsky, A.A.  
**ORCID:** 0009-0008-6009-3196  
**Status:** `PROVED_BOUNDED_RESULTS / MANUSCRIPT_INTEGRATION_PENDING`

This note answers the next inverse problem raised by Article II:

> What can be reconstructed from reduced backtracking / square / braid holonomies?

The answer has two parts. First, loop holonomies alone do **not** identify an arbitrary UCP channel, even if all closed loops of the adjacent-transposition graph are known. Second, in a local Markovian qubit model, a finite set of first-order backtracking and braid coefficients does identify the complete dissipative Kossakowski matrix, and hence the generator modulo Hamiltonian derivations.

## 1. Transport operator system: the maximal possible target

Fix an Article-I unitary family and let `T` denote the collection of exact contextual edge transports generated by adjacent swaps. Define the transport operator system

`S_T := span_C { I, T, T^* : T in T }`.

### Proposition 1.1 — restriction ceiling

If two UCP maps `Phi` and `Psi` agree on `S_T`, then every reduced edge image and hence every reduced loop holonomy built from this transport family is identical for `Phi` and `Psi`.

#### Proof

Every reduced edge is `Phi(T)` for some `T in T` (or the adjoint orientation). Agreement on `S_T` gives equality edge by edge. Products around any loop are therefore equal. QED.

Consequently, no holonomy protocol using only one fixed transport family can identify the full channel outside the operator system sampled by that family.

## 2. Strong no-go: all loop holonomies can fail to identify even the channel on the transport family

Let `sigma=(sigma_x,sigma_y,sigma_z)` and choose three unit vectors with pairwise angle `pi/4`:

`n_1 = (1,0,0)`,

`n_2 = (1/sqrt(2), 1/sqrt(2), 0)`,

`n_3 = (1/sqrt(2), 1-1/sqrt(2), sqrt(sqrt(2)-1))`.

They satisfy `n_i . n_j = 1/sqrt(2)` for all `i != j`. Put

`U_i := n_i . sigma`.

Each `U_i` is a self-adjoint unitary. For a swapped pair let

`G_ij := U_j U_i U_j U_i = (U_j U_i)^2`.

Since the angle is `pi/4`,

`tr(G_ij) = 2 cos(2*pi/4) = 0`.

Every contextual edge transport is a unitary conjugate `P G_ij P^*`, and therefore is also traceless.

For the qubit depolarizing family define

`Phi_eta(A) = eta A + (1-eta) tr(A) I/2`,

which is UCP for `-1/3 <= eta <= 1`.

### Theorem 2.1 — even-loop depolarizing sign ambiguity

For the above transport family and any closed adjacent-transposition loop `L` of length `m`,

`H_eta(L) = eta^m I`.

Therefore, for every `0 < r <= 1/3`, the two distinct UCP channels `Phi_r` and `Phi_{-r}` have identical reduced holonomy on **every closed loop**:

`H_r(L) = H_{-r}(L)` for all `L`.

#### Proof

Every contextual edge transport `T_e` is traceless, so `Phi_eta(T_e)=eta T_e`. The unreduced contextual connection is exactly flat, hence for any closed loop

`T_m ... T_1 = I`.

Thus

`H_eta(L)=Phi_eta(T_m)...Phi_eta(T_1)=eta^m I`.

The Cayley graph of `S_n` generated by adjacent transpositions is bipartite by permutation parity: every generator reverses parity, so every closed loop has even length. Hence `r^m=(-r)^m`. Both `Phi_r` and `Phi_{-r}` are UCP when `0<r<=1/3`, and they are distinct because their action on any nonzero traceless operator has opposite sign. QED.

### Consequence 2.2

Even the **complete closed-loop holonomy data set** need not determine a UCP channel. In this example it determines `|eta|` but not the sign of `eta`.

This obstruction is stronger than a square/braid-only ambiguity because it survives after all closed loops are included.

## 3. What the infinitesimal defect determines

Let `L_1,L_2 : M_d(C) -> M_d(C)` be bounded unital *-preserving generators and define

`Gamma_L(X,Y) := L(XY)-L(X)Y-X L(Y)`.

### Proposition 3.1 — generator identifiability modulo derivations

The following are equivalent:

1. `Gamma_{L_1} = Gamma_{L_2}` on all pairs `(X,Y)`;
2. `D := L_1-L_2` is a derivation.

On `M_d(C)`, every derivation is inner. For *-preserving generators there exists a self-adjoint `H_0` such that

`L_1-L_2 = i[H_0, . ]`.

Thus the full bilinear defect `Gamma_L` determines a finite-dimensional Markov generator exactly modulo a Hamiltonian derivation.

#### Proof

Equality of the two `Gamma` forms means

`D(XY)-D(X)Y-XD(Y)=0`

for all `X,Y`, which is exactly the Leibniz rule. Conversely every derivation has zero Leibniz defect. Derivations of full matrix algebras are inner; *-preservation fixes the implementing inner derivation to Hamiltonian form up to an irrelevant scalar multiple of the identity. QED.

This gives the correct identifiability target for infinitesimal reduced holonomy: the dissipative generator modulo coherent Hamiltonian motion.

## 4. Qubit Kossakowski coordinates

Work in the canonical unital qubit GKSL gauge in which the Kossakowski matrix is real symmetric,

`C = [[c_xx,c_xy,c_xz], [c_xy,c_yy,c_yz], [c_xz,c_yz,c_zz]]`,

with `C >= 0` for a physical dissipator. The corresponding Leibniz defect is

`Gamma_C(X,Y) = sum_{a,b in {x,y,z}} C_ab [sigma_a,X][Y,sigma_b]`.

The six real coordinates are ordered as

`c = (c_xx,c_yy,c_zz,c_xy,c_xz,c_yz)^T`.

We now use the Article-I three-gate spin tuple

`U_1 = sigma_x`,

`U_2 = (sigma_x+sigma_y)/sqrt(2)`,

`U_3 = (sigma_x+sigma_z)/sqrt(2)`,

and the contextual braid loop

`123 -> 213 -> 231 -> 321 -> 312 -> 132 -> 123`.

Let `T_1,...,T_6` be its exact contextual edge transports, so `T_6...T_1=I`.

Define the first-order braid coefficient

`B(C) := - sum_{k=2}^6 T_6...T_{k+1} Gamma_C(T_k,P_{k-1})`,

where `P_{k-1}=T_{k-1}...T_1`.

For each edge define the right-backtracking first-order coefficient

`R_j(C) := - Gamma_C(T_j^*,T_j)`.

## 5. Finite holonomy tomography of the unital qubit dissipator

Consider the six real scalar measurements

`m(C) := (`

`  Re B_11,`

`  Re B_12,`

`  Im B_12,`

`  Re (R_5)_11,`

`  Re (R_1)_11,`

`  Re (R_6)_11 )^T`.

### Theorem 5.1 — six-parameter dissipative identifiability

In the coordinate vector `c=(c_xx,c_yy,c_zz,c_xy,c_xz,c_yz)^T`,

`m(C)=M c`,

with

```text
M = [ -6  -8  -8   0   0   2
       0   0   2   0   4  -2
       0   2   0   4   0  -2
      -4   0  -4   0   0   0
      -4  -4   0   0   0   0
      -2  -2  -2   2   2   2 ]
```

and

`det(M)=8192 != 0`.

Therefore these six first-order holonomy/backtracking scalars uniquely determine the full real symmetric Kossakowski matrix `C`.

Combined with Proposition 3.1, this finite data set identifies the bounded unital qubit Lindblad generator modulo its Hamiltonian derivation.

#### Proof

Substitute the explicit Article-I edge transports into the definitions of `B(C)` and `R_j(C)`, expand `Gamma_C` in the six symmetric Pauli-Kossakowski basis elements, and collect the displayed six real matrix entries. The resulting integer matrix is `M`. Direct elimination, or exact determinant evaluation, gives

`det(M)=8192`.

Hence `M` is invertible over `R`. QED.

### Proposition 5.2 — braid information is genuinely additional for this design

Using all right/left first-order backtracking matrices of the six contextual edges, but omitting the braid coefficient, the measurement map on `Sym_3(R)` has rank `5`.

Adding the braid coefficient raises the rank to `6`.

Thus the braid loop supplies a dissipative direction that the local backtracking Schwarz defects alone do not resolve for this transport design.

The deterministic verification script `examples/identifiability_qubit_v010.py` computes these ranks and the measurement matrix.

## 6. Interpretation boundary

Theorem 5.1 is an **algebraic identifiability theorem**, not yet an experimental tomography protocol. It assumes access to the indicated matrix-valued first-order coefficients (or equivalent scalar matrix elements). It does not include sampling noise, state-preparation/measurement restrictions, query complexity, or hardware errors.

Likewise, the theorem identifies the canonical unital qubit dissipative Kossakowski matrix. It does not contradict the general no-go theorem for arbitrary finite-time UCP channels: local Markov-generator identification uses infinitesimal, oriented, matrix-valued data and a restricted model class, while Theorem 2.1 concerns closed-loop finite-channel data without such model assumptions.
